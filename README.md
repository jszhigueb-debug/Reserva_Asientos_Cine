## Descripción del proyecto

Este proyecto consiste en desarrollar un programa en Python que simula la reserva de un asiento en una sala de cine pequeña.

La sala cuenta con 12 asientos organizados en una matriz de 3 filas por 4 columnas.

- 0 = Asiento libre
- 1 = Asiento reservado

## Objetivo

Aplicar los conocimientos sobre arreglos multidimensionales mediante la creación de una matriz de 3 filas por 4 columnas y el uso de bucles anidados.

2. Tener Python instalado.
